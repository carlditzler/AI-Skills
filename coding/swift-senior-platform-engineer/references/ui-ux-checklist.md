# Apple-platform UI and UX checklist
- Prefer native controls and behavior over custom chrome.
- Respect hierarchy, spacing, typography, and motion guidance from HIG.
- Support dynamic type, dark mode, keyboard use where relevant, and accessibility semantics.
- Design empty, loading, error, success, disabled, and retry states together.
- Avoid clutter, cramped layouts, ambiguous icons, and hidden actions.
- macOS work should feel macOS-native, not like a stretched iOS app.
