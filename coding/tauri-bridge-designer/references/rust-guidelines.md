# Rust Guidance

- Rust docs: https://doc.rust-lang.org/
- Rust API Guidelines: https://rust-lang.github.io/api-guidelines/about.html
- Naming guidance: https://rust-lang.github.io/api-guidelines/naming.html
- Checklist: https://rust-lang.github.io/api-guidelines/checklist.html

Prefer:
- clear types over bool flags
- explicit error types
- narrow public APIs
- naming that distinguishes getters, conversions, and builders
