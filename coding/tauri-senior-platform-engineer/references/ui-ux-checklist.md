# Desktop UI and UX checklist for Tauri apps
- Make the app feel like a real desktop product, not a thin wrapped webpage
- Respect resize behavior, keyboard shortcuts, focus states, and input affordances
- Design loading, empty, error, success, disabled, and retry states together
- Use clear hierarchy, restrained motion, strong spacing, and deliberate affordances
- Handle offline, file permission, path, and OS error cases explicitly
- Avoid excessive web-style chrome that clashes with desktop expectations
- Ensure contrast, semantics, and keyboard navigation are present

- Choose the frontend framework idiom that matches the repo and keep the UI consistent with that framework, rather than mixing patterns.
