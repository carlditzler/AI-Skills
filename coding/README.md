# Coding Skills

A collection of coding skills for Codex and Claude Code so Codex and Claude Code are more effective coding agents by providing them with guidance, quality bars, and better direction.

These skills are intended to help with:
- feature implementation
- debugging
- code review
- refactoring
- testing
- performance work
- UI and UX quality

And, are specific for Swift, Kotlin, Flutter, and Tauri.
