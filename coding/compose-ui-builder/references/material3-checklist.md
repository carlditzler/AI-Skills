# Material 3 Checklist

- Material 3 site: https://m3.material.io/
- Compose implementation guidance: https://developer.android.com/develop/ui/compose/designsystems/material3
- Components: https://m3.material.io/components

Verify before shipping:
- color roles come from theme rather than scattered literals
- typography scale is coherent
- shapes and elevation are consistent
- screen adapts across widths where needed
- accessibility semantics are present for custom elements
